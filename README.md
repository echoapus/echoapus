### 🚀 Featured Projects / 精選專案

#### 🌐 Network Operations & Security / 網路運維與安全
*   **[BgpFlowspecReceiver](https://github.com/echoapus/BgpFlowspecReceiver)**
    *   *EN*: BGP Unicast and FlowSpec receiver with a live SSE web UI. Connects to a peer router, maintains an in-memory RIB, and streams updates directly to the browser.
    *   *ZH*: 支援 BGP 單播與 FlowSpec 接收器，附帶即時的 SSE Web 介面。連接至對等路由器，維護記憶體中的 RIB，並直接串流更新至網頁。
*   **[simple-nms](https://github.com/echoapus/simple-nms)**
    *   *EN*: A lightweight Network Management System (NMS) collecting Syslog (RFC 3164/5424), SNMP Traps, and Webhooks into SQLite, featuring a real-time web dashboard.
    *   *ZH*: 輕量級網路管理系統 (NMS)，可在單一 SQLite 資料庫中收集 Syslog、SNMP Trap 和 Webhook 事件，並配有即時的 Web 監控儀表板。
*   **[sonargrid](https://github.com/echoapus/sonargrid)**
    *   *EN*: A centralized, agentless network information collection tool for device discovery, inventory tracking, and topology inference.
    *   *ZH*: 集中式、免安裝 Agent 的網路資訊收集工具，用於設備發現、資產盤點和網路拓撲推導。
*   **[mercury](https://github.com/echoapus/mercury)**
    *   *EN*: A high-performance IPFIX traffic generator skeleton written in Rust.
    *   *ZH*: 使用 Rust 編寫的高效能 IPFIX 流量生成器框架。
*   **[dnsStressTest](https://github.com/echoapus/dnsStressTest)**
    *   *EN*: A lightweight Python tool for DNS server stress and load testing.
    *   *ZH*: 用於 DNS 伺服器壓力與負載測試的輕量化 Python 工具。
*   **[mausezahn (Fork)](https://github.com/echoapus/mausezahn)**
    *   *EN*: An enhanced fork of the Mausezahn traffic generator with native IPv6 support.
    *   *ZH*: 為 Mausezahn 流量生成器添加原生 IPv6 支援的增強分支版本。
